# RESOURCES.md 格式

`RESOURCES.md` 是本主题的精选可信来源集合。解释中的知识应该从这里获取，而不是从参数化猜测来。智慧来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书：《力量训练科学与实践》，Zatsiorsky & Kraemer 著](https://example.com)
  关于训练计划和适应的基础文本。用于：任何与周期化、恢复、强度区间有关的内容。
- [文章："我该练多少？" Greg Nuckols 著（Stronger By Science）](https://example.com)
  基于证据的训练量里程碑综述。用于：每个肌群的每周组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信号 subreddit，压制伪科学。用于：计划点评、瓶颈排查。
- 本地：{某健身房} 周二力量课
  用于：举起动作的实时教练反馈。
```

## 规则

- **只收高可信度。** 优先采用一手来源、公认专家、同行评审成果和强管理的社区。如果一个资源是伪装成教育的营销，别放进来。
- **每条都加注释。** 一个裸链接三个月后毫无用处。加一行：它覆盖什么，什么时候用它。
- **按知识/智慧分组。** 对应 [SKILL.zh.md](./SKILL.zh.md) 中的哲学。一个资源只出现在一个组是可以的。
- **明确标出缺口。** 如果使命需要的某个领域没有好的资源，写一个 `## 缺口` 章节列出缺少什么。这驱动未来的搜索。
- **无情清理。** 一个被证明是错的、浅的、或偏离使命的资源应该移除，而不是埋掉。五个锐利的来源比三十个平庸的强。
- **记录社区偏好。** 如果用户选择不加入社区，在这里注明，这样未来的会话不会继续提议。
