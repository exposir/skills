# RESOURCES.md 格式

`RESOURCES.md` 是本主题精选的可信来源。课里的知识从这来，不从脑补来。智慧从这列的社区来。

## 结构

```md
# {主题} 资源

## 知识

- [书：《力量训练科学与实践》，Zatsiorsky & Kraemer 著](https://example.com)
  训练计划和适应的基础文本。用于：周期化、恢复、强度区间。

- [文章："我该练多少？" Greg Nuckols 著（Stronger By Science）](https://example.com)
  基于证据的训练量综述。用于：每周每肌群组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信号 subreddit，杀伪科学。用于：计划点评、瓶颈排查。

- 本地：{某健身房} 周二力量课
  用于：动作实时教练反馈。
```

## 规矩

- **只收高可信的。** 一手来源、公认专家、同行评审、强管理的社区。伪装成教育的营销别放。
- **每条加注释。** 裸链接三个月后没用。加一行：管什么、什么时候用。
- **按知识/智慧分。** 对应 [SKILL.zh.new.md](./SKILL.zh.new.md) 的哲学。一个资源只归一组。
- **缺口明说。** 使命需要的领域没资源，写 `## 缺口`，列缺什么。这驱动后面的搜索。
- **无情清理。** 错的、浅的、偏题的，删掉，别埋。五个锐利的好过三十个平庸的。
- **记社区偏好。** 用户不想加社区，写这，免得以后反复提。
