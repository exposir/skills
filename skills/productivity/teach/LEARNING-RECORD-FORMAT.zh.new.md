# 学习记录格式

记录放在 `./learning-records/`，编号递增：`0001-slug.md`、`0002-slug.md`。目录懒建：写第一条时才建。

教学版的 ADR：记不太明显的教训、关键洞察、已知的先前知识，后面靠它们算最近发展区。

## 模板

```md
# {学到或确立的短标题}

{1-3 句话：学到了什么，或确立了什么先前知识，以及为什么它改变接下来的教学。}
```

就这。一个段落就够了。价值在于记下"这个现在知道了"和"为什么它改变接下来该教什么"，不是填表。

## 可选部分

真有用才加，多数记录用不上。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：早期理解后来被推翻时用。
- **Evidence**（证据）：用户怎么展示了这个理解（答对问题、做完练习、说过先前经验）。以后可能被重新审视时用。
- **Implications**（影响）：对未来会话解锁了什么、排除了什么。不明显时记。

## 编号

看 `./learning-records/` 里最大的号，加一。

## 什么时候写

四个条件，满足任一就写：

1. **用户展示了对非平凡东西的真正理解**：不只是接触过，有证据表明能正确用。这为接下来教什么拉高了底线。
2. **用户透露了先前知识**："我本来就会 X。"记下来，外加会到什么程度。以后别重复教。
3. **一个误解被纠正了**：用户之前信错了，现在明白了为什么。价值很高：能预测相关主题以后的绊脚石。
4. **使命因学习而变了**：用户发现自己在乎的不是原来想的那个。交叉链接到 [[MISSION.md]] 并更新它。

### 不算的

- 过了一遍材料。过一遍不算学会。等证据。
- 已经在 [[GLOSSARY.md]] 里收成术语的东西。不重复。
- 逐会话流水账。这是决策级洞察，不是日记。

## 取代

后来的记录跟前面的矛盾，把旧的标成 `Status: superseded by LR-NNNN`，别删。理解怎么走到今天的，本身就是信号。
