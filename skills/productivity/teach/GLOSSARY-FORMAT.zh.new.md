# GLOSSARY.md 格式

`GLOSSARY.md` 是本工作区的标准语言。所有解释、练习、学习记录都得用它的词。建它本身就是学习：把概念压成一行定义，说明用户真懂了。

## 结构

```md
# {主题} 术语表

{一两句话说明这术语表管什么。}

## 术语

**肌肉肥大（Hypertrophy）**：
训练中机械张力和代谢压力反复刺激带来的肌肉增长。
_别用_：增肌、变大

**渐进超负荷（Progressive overload）**：
用负荷、容量或强度，随时间系统性地推高对肌肉的要求。
_别用_：加码、升级

**RPE（自觉费力程度）**：
一组多累，1 到 10 自评。10 是力竭，8 表示还能再来两下。
_别用_：努力分、强度分
```

## 规矩

- **懂了才进。** 术语表是压缩知识的存档，不是词典。用户刚接触，等他们能用对了再提进来。
- **要有主见。** 同一概念多个词，定一个，剩下的标为别用。语言得压缩。
- **定义要短。** 一两句。说它是什么，不说它干什么或怎么干。
- **定义里用术语表自己的词。** 一个词进了表，哪都用它，包括别的定义里。这才是复杂术语后面好懂的原因。
- **自然成组就加子标题。**（`## 解剖学`、`## 编程`）。平铺也行。
- **歧义明说。** 领域里乱用的词，写清楚："本工作区里'组'指正式组，热身另算。"
- **理解深了就改。** 第一周对的，第六周可能错。原地改，别留旧的。
