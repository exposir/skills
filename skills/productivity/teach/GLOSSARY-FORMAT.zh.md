# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的规范语言。所有解释、练习和学习记录都应遵守它的术语。构建它本身就是学习的一部分：把一个概念压缩成紧凑的定义，是用户理解它的证据。

## 结构

```md
# {主题} 术语表

{一两句话描述本术语表涵盖的主题。}

## 术语

**肌肉肥大（Hypertrophy）**：
由重复训练中机械张力和代谢压力驱动的肌肉增长。
_避免用_：增肌、变大

**渐进超负荷（Progressive overload）**：
通过负荷、容量或强度，系统性地随时间增加对肌肉的需求。
_避免用_：加码、升级

**RPE（Rate of Perceived Exertion，自觉费力程度）**：
一组训练感觉有多累的 1 到 10 自评，10 是力竭，8 表示还剩两下。
_避免用_：努力分、强度评级
```

## 规则

- **只在用户理解之后才加术语。** 术语表是压缩知识的记录，不是用户用来学习新词的词典。如果用户刚接触一个概念，等到他们能正确使用它，再提升到这里。
- **要有主见。** 当同一个概念有多个词，挑最好的，把其余的列为该避免的别名。这就是语言压缩的方式。
- **定义要紧凑。** 一两句话。定义这个词是什么，不是它做什么或怎么做。
- **在定义里用术语表自己的词。** 一旦术语进了术语表，在任何地方都用它，包括在其他定义里。这正是让复杂术语后面更容易理解的原因。
- **自然形成群体时，用子标题分组。**（比如 `## 解剖学`、`## 编程`）。术语之间是连贯的，平面列表也可以。
- **明确标记歧义。** 如果某个术语在更广的领域里被随意使用，注明解决方式："在本工作区，'组'总是指正式组；热身另算。"
- **随着理解加深而修订。** 用户第一周写的定义，到第六周可能就错了。原地更新；不要留下过时的条目。
