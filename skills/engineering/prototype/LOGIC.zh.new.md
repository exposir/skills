# 逻辑原型

一个自包含的单个 HTML 文件（一份**能转发的演示**），谁都能点按钮驱动一个状态模型。问题关乎**业务逻辑、状态转移、数据形状**的时候用它：这类东西纸面上看着都对，只有拿真实场景硬推一遍才会露馅。

单文件、零安装，所以能甩给非开发人员（设计师、PM、领域专家），让他们亲手摸这个模型。也因此它要说人话，不说代码话。

## 什么时候该走这条路

- "我不确定这状态机处理不处理得了先 X 后 Y 的边角。"
- "这数据模型真的表达得了……那种情况吗？"
- "动手写之前我想先摸摸 API 该长什么样。"
- 任何想**按按钮、看状态变**的场景。

如果问的是"这该长什么样"，走错路了。去 [UI.zh.new.md](UI.zh.new.md)。

## 怎么做

### 1. 把问题写出来

写代码之前，先写清你在给哪个状态模型、哪个问题做原型。一段话，放在演示最顶上（要看得见的简介，不是藏进注释）。答错问题的逻辑原型是纯浪费，所以把问题摊开，方便事后对账，不管用户是现在盯着看还是离开后回头再看。

### 2. 把逻辑关进一个能拎走的模块

真正的逻辑（负责回答问题的部分）放进一个 `<script>` 块，写成一个小巧的纯模块，将来能原样拎进真实代码库。包着它的页面是一次性的；这个模块不是。

长什么样取决于问题：

- **纯 reducer**：`(state, action) => state`。动作是离散事件、状态是一个值的时候用。
- **状态机**：状态和转移都写明白。"此刻哪些动作合法"本身就是问题的一部分时用。
- **一组纯函数**，作用于一个朴素数据类型。没有隐含的当前状态、只有变换时用。
- **类或模块，方法面清晰**：逻辑确实攥着持续的内部状态时用。

挑最贴问题的形态，_不是_最好往页面上接的那个。保持纯粹：不碰 DOM，不碰 `document`，按钮处理器不许伸进去。只有页面调它，没有反向流动。原型能活得比自己久，靠的就是这个：问题一有答案，验证过的 reducer / 状态机 / 函数组就能自己搬进真实模块。

### 3. 搭那个能转发的 HTML 文件

一个文件，裸 HTML/CSS/JS：不上框架，不搞打包器，不起服务器，全内联，双击就开，邮件转发也不烂。谁打开都能跑。

按给非开发人员看的标准写。每个标签都是**领域语言**，不是代码：按钮和状态读起来像业务，不像 reducer。用大白话讲清正在发生什么。

从上到下排清楚：

1. **标题 + 一句话说明**，讲这演示让你探索啥（就是第 1 步那个问题）。
2. **当前状态**：完整相关状态渲染成能读的面板（带标签的字段，不是裸 JSON 糊一脸），每次点击重渲染，变化看得见。非开发人员容易跟丢的地方，专门点一句"刚才变的是这"。
3. **自由点**：每个动作一个按钮，永远在场，谁都能随便乱序地戳。每点一下分发动作、重渲染状态。
4. **引导演示**：一组**场景**，一个场景一个标签。标签里先是短白话（这场景摆什么局、该盯什么），下面是该场景**按顺序点的按钮**。每一步都是真按钮：点了就执行、进入下一步。开始演示先重置到已知初始态，保证每次跑法一样。

场景专挑别扭的：快乐路径、一个棘手的边角、一次本该被拒绝的尝试。就是纸面上难推的那几个。

好看但克制：干净排版、宽松留白、一种强调色。不要动画，不要噱头，什么都别跟状态和按钮抢戏。

### 4. 交出去

文件发给对方，或直接帮人打开。他们得空自己点完引导和自由玩；最值钱的时刻是他们脱口而出"等等，这不该能发生啊"或"咦，我以为 X 会是另一个样"：那些是_想法_里的 bug，也正是这原型的全部目的。要新动作、新场景就加，原型本来就是会长的。

### 5. 存档：答案和原型都要

原型答完问题，先存答案，再按 [SKILL.zh.new.md](SKILL.zh.new.md) 的路子存原型。逻辑分支的对应关系：验证过的 reducer / 状态机 / 函数组搬进真实模块（决策被吸收）；HTML 壳跟着进一次性分支，原型作为一手来源躺在那，而且自包含单文件，在那照样双击重跑。

## 别干的事

- **别加测试。** 需要测试的原型已经不是原型了。
- **别接真数据库。** 用内存状态，除非问的就是持久化。
- **别泛化。** 别想"以后要是想支持 X 呢"。原型只答一个问题。
- **别把逻辑和页面搅在一起。** 纯模块里出现 DOM、`document` 或按钮处理器，它就没法拎走了。页面只能是纯模块外面的一层薄壳。
- **别上框架、打包器、服务器。** 要的是收件人双击即开；React 应用或 dev server 直接杀掉"能转发"。
- **别把 HTML 壳送进生产。** 页面是为手点浏览优化的。壳后面那个逻辑模块才是值得留的东西。
