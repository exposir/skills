name: research
description: 针对一个高可信度的一手来源调查问题，并把发现整理成一个 Markdown 文件存入仓库。当用户想研究某个主题、收集文档或 API 事实、或把阅读跑腿活交给后台 agent 时使用。
---

启动一个**后台 agent** 去做研究，这样它读的时候你继续干活。

它的任务：

1. 针对**一手来源**（官方文档、源代码、规格、第一方 API）调查问题，而不是二手的转述。每条论断都追溯回拥有它的那个来源。
2. 把发现写进一个 Markdown 文件，每条论断都注明来源。
3. 存到仓库本来就放这类笔记的地方；沿用现有惯例，如果没有惯例，就放到一个合理的位置并说明放哪了。
